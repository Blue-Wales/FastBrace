# Technical Support

If you run into problems while using FastBrace, you can get help through the following channels.

## Reporting Issues

- **GitHub Issues**: submit bug reports and feature suggestions to [GitHub Issues](https://github.com/Zhouguangminggit/FastBrace/issues); please include reproduction steps and environment details whenever possible
- **GitHub Discussions**: for usage questions and design discussions, visit [GitHub Discussions](https://github.com/Zhouguangminggit/FastBrace/discussions)

## Before You Ask

To locate problems faster, please confirm the following before reporting:

1. You have read the relevant documentation: [Quick Start](/en/intro/getting-started), [Architecture Guide](/en/advanced/architecture/domain-layer)
1. Your Python and dependency versions meet the [environment requirements](/en/intro/getting-started#requirements)
1. You have searched existing issues to avoid duplicates

## Contributors

Thanks to all developers who have contributed to FastBrace. You are welcome to join in by submitting issues, pull requests, or improving the documentation.
