# 技术栈

FastBrace 的技术选型围绕三个目标：**高性能**、**工程化**、**对 AI 友好**。本页列出框架使用的核心技术组件信息，建议在使用脚手架前先学一下以下内容，提前了解和学习这些知识，会对脚手架的使用更加得心应手。



## 运行环境

| 组件     | 版本要求  | 说明                                                       |
| -------- | --------- | ---------------------------------------------------------- |
| Python   | 3.10+     | 使用现代类型注解与异步特性                                 |
| MySQL    | 8.x       | 业务数据存储，默认 `utf8mb4` 字符集                        |
| Redis    | 6+        | 缓存、登录态与 Celery Broker                               |
| uv       | 最新稳定版 | 统一管理 Python 版本、虚拟环境与依赖，替代 pip/poetry 等工具 |



## 核心依赖

| 类别         | 组件               | 版本      | 用途                                                     |
| ------------ | ------------------ | --------- | -------------------------------------------------------- |
| Web 框架     | FastAPI            | 0.109+    | 高性能异步 API 框架，内置 OpenAPI/Swagger 文档            |
| ASGI 服务器  | Uvicorn           | 0.27+     | 生产级 ASGI Server，`main.py` 中一键启动                  |
| ORM          | SQLAlchemy        | 2.0+      | 数据库模型定义与异步/同步数据访问                         |
| 数据库驱动   | PyMySQL           | 1.1+      | MySQL 连接驱动                                            |
| 数据库迁移   | Alembic           | 1.13+     | 数据库结构版本管理与迁移                                  |
| 配置管理     | Pydantic Settings | 2.0+      | 类型安全的配置模型与环境变量管理                          |
| 数据校验     | Pydantic          | 2.0+      | 请求/响应模型定义与校验                                   |
| 认证         | PyJWT / bcrypt    | 2.10+/4.3+ | JWT 令牌签发校验与密码哈希                                |
| 缓存         | Redis (redis-py)  | 5.0+      | 缓存连接与登录态管理                                      |
| 任务队列     | Celery            | 5.3+      | 异步任务与事件处理                                        |
| 定时调度     | Celery Redbeat    | 2.3+      | Redis 存储的周期任务调度器                                |
| 日志         | Loguru            | 0.7+      | 结构化日志，替代标准库 logging                            |
| 加密         | cryptography      | 42.0+     | RSA 密码加密（RSA-OAEP-SHA256）                           |
| 对象存储     | oss2              | 2.18+     | 阿里云 OSS 文件上传（可选）                               |
| 模板         | Jinja2            | 3.1+      | 邮件等模板渲染                                            |

> 完整的版本约束以项目根目录 `pyproject.toml` 的 `dependencies` 为准，安装依赖统一执行 `uv sync --all-extras`。
